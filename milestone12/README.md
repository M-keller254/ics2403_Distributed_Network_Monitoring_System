# Milestone12 (Week 12)

This folder is a complete, runnable snapshot of the system as of
Milestone 12: **MinIO object-storage archive and telecom capstone integration**.

The monitoring, state, and storage services are included in this capstone
stack. Kafka event streaming is demonstrated separately in Milestone 11.
See `README_MILESTONE12.md` for this week's specific
goal, design, and measured results. Earlier `README_MILESTONEx.md`
files are kept for weeks 11 and earlier.

## Run it
```powershell
docker compose up --build
```
